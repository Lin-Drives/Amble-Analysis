# Senno Gait（セノゲイト）深度产品档案
（调研日期：以当前会话为准；所有日文资料要点已翻译为中文）

## 0. 一句话结论
Senno Gait 是**中国深圳创感科技（Sennotech）研发的"传感器鞋垫+手机App"步态分析系统**，由日本小微鞋垫公司 **SK8INSOLL株式会社** 在日本独家代理，包装为"AI步行姿势分析支援系统"，切入介護预防市场。其核心差异化不是 AI 本身，而是**"AI测量 → A.I.健康歩行診断士培训认证 → 鞋垫/鞋销售"的服务+培训+商品闭环**。注意：它**不是纯视觉方案**（依赖传感器鞋垫硬件），与 GaitGuardian 的单目视频路线不同，可比对象更接近 LocoStep / CareWiz トルト。

## 2. 产品功能与使用流程

### 硬件与流程（关键：需要专用传感器鞋垫）
- 鞋垫内置 **16个压力传感器阵列 + 9轴IMU（100Hz采样）**，蓝牙4.0与手机连接
- 流程：① 把传感器鞋垫放入利用者鞋中（需取出原鞋垫、穿平底/运动鞋）→ ② 站定校准 → ③ 自然直线行走约30秒（官方宣传"30秒步行"），操作员手持 iPhone/iPad 跟随（被测者与设备蓝牙距离≤4米），跑步机亦可 → ④ 数据自动上传云端 → ⑤ 约10秒~2分钟内 AI 从80万~100万人大数据中生成报告，可当场用智能手机向本人/家属说明
- 输出指标：步长/步幅、步速、步频、站立相/摆动相时间占比、双支撑时间、左右对称性、着地角/离地角、最大摆动速度、足底压力与COP（力中心）轨迹、足内翻/外翻（pronation/supination）、摆动分析、时空参数；步态动画3D重现；另有姿势分析（拍照）
- 报告形态：App内图文报告（分 Pri / Basic 级别），可生成 URL 链接（gait.sennoapi.com/reports/...）在 PC 浏览、打印、导出 PDF / Excel 原始步态数据
- AI 引擎说明：官网表述为"80万人以上大数据 + 深度学习，AI 自动提示步态习惯、负担部位、未来步行风险与解决方案"；Sennotech 官网称融合传感器+RGB相机机器视觉，但日本介護场景实际只推鞋垫路线。**更细的算法技术白皮书未见公开**
- 来源：https://ai-walking.com/ ｜ https://www.sennotech.com/en/productGait ｜ https://pdf.medicalexpo.com/pdf/sennotech/user-guide-sennogait-english/124765-240414.html ｜ https://www.medicalexpo.com/ja/prod/sennotech/product-124765-919475.html

## 8. 对 GaitGuardian 的启示

1. **测量本身不收费难，"测量→处方→商品/服务"闭环才赚钱**：Senno Gait 的全部商业设计都指向保险外商品（鞋垫/鞋）销售；LocoStep 则靠保险算定（250点/次）变现。GaitGuardian 的"自动生成康复训练处方"若能衔接课程/服务/商品交付，比单纯卖测量更有商业价值。
2. **"服务+培训认证"是低成本分销网络**：A.I.健康歩行診断士体系把介護职员、店员变成有销售权限的认证节点（3300日元入门→14.8万日元高级），同时解决了"现场没有PT"的人力瓶颈。中国社区养老同样缺专业人才，可借鉴"轻认证+分级授权"模式。
3. **日本介護预防的落地场景清单**：自治体委托的介護予防教室/通いの場（如宫崎县新富町22个场所用トルト做年度体能对比）、健康测量会、百货店柜台、设施集客活动——对应中国的社区居家养老服务中心、老年健康小屋、党群服务中心活动，GaitGuardian 应优先争取**街道/社区级采购和长期护理保险试点场景**，而非直接C端获客。
4. **补贴/支付通道设计**：日本走介護ロボット助成金（都道府县年度募集）与保险算定双通道；中国可对应民政系统的智慧健康养老产品目录、长护险、适老化改造补贴。
5. **技术路线警示**：Senno Gait 证明"有硬件才有足底压力数据"，但其 iOS 限定+硬件依赖也限制了规模；LocoStep/トルト 证明纯视觉方案在日本已能进医疗器械与保险体系。GaitGuardian 的单目视频路线在日本对标的是 LocoStep，应关注其"17骨骼点、5米正面步行、10秒测量、可保险算定"的产品定义作为基准线，并以"下肢肌力分级+关节问题识别"做出超出步速指标的差异化。
6. **循证先行**：日本头部玩家均绑定大学监修与共同研究（顺天堂、神户大学、国立长寿医疗研究中心），AMED 国家级项目都在做 frail RCT；GaitGuardian 若进入养老渠道，需尽早布局与康复医学科/体育院校的精度验证论文。
