### 1.3 政府/机构项目

- **FARSEEING**(欧盟 FP7):300+ 起真实世界跌倒的可穿戴信号数据库,跌倒机制研究标杆
- **PreventIT / iStoppFalls**(欧盟):社区老人个性化 ICT 运动干预,处方设计范式
- **世界跌倒预防指南(2022)**:社区中风险老人应提供个体化平衡+力量训练——**处方库的循证依据**
- **日本厚労省科研课题**:智能手机视频 AI 推定ロコモ(运动功能退化)等级,报告"高精度确认"——国家级验证
- **软银衰弱预防实证**:手机自动采集步速/稳定性,AI 判定衰弱风险

### 1.4 竞品格局结论

> **"纯手机视频→步态评估→跌倒风险"在德国(LINDERA)、日本已反复验证,但全球尚无"病因分型+肌力分级+自动处方"全闭环 C 端产品**——这正是 GaitGuardian 方案文档中判断的空白,调研予以确认。数字 MSK 巨头(Hinge $6.5B、Sword $4B)刻意避开老年跌倒/诊断市场,差异化空间成立。商业模式(子女付费?社区/长护险?B2B2C?)需与技术同等优先级验证——LINDERA 走护理机构、日本产品走医生工具,纯家庭付费模式全球尚无成功先例。

## 第二部分:可直接获取的公开数据集(核心问题)

### 2.1 ⭐ 视频+临床标签类(最对口,优先获取)

|--------|------|------|------|--------|

## 第三部分:零采集成本冷启动管线(Phase 0 建议)

刻意分层"商用安全数据"与"研究专用数据",确保交付模型不被许可污染:

| 层 | 任务 | 用什么 | 许可风险 |
|----|------|--------|----------|
| L0 | 2D 姿态 | MediaPipe / RTMPose 官方权重 | 无 |
| L1 | 2D→3D lifting 预训练 | **CMU MoCap + AIST++**(MotionBERT 式掩码重建);H36M/AMASS 仅研究期基准不进交付模型 | 商用安全池 ✅ |
| L2 | 步态特征管线验证 | OU-MVLP(2–87 岁)+ CASIA-B 自跑姿态→步态参数,建年龄分层参考区间 | 申请制 |
| L3 | 临床分型 | **GAVD**(视频+病理)+ **CARE-PD**(SMPL+严重度) | CARE-PD 非商用 ⚠️ |
| L4 | 肌力推断(替代监督链) | **AddBiomechanics**(运动学→力矩)→ **SIAT-LLMD/Lencioni**(EMG↔力矩)→ **OpenCap Monocular** 对公开视频批量生成仿真肌肉力弱标签→蒸馏到轻量模型 | 均开放 ✅ |
| L5 | 康复处方动作 | **KIMORE**(评分)+ **UI-PRMD**(商用安全)+ Keraal/FineRehab | 基本安全 |
| 上线后 | 肌力弱标签迭代 | App 内 30 秒椅子站立等功能代理指标 | 自有数据 |

**六份立即可下、合计零成本、其中四份商用安全的核心数据**:CMU MoCap、AIST++、UI-PRMD、AddBiomechanics + SIAT-LLMD、KIMORE。

**商用合规红线**:CARE-PD / MOBILISE-D / CCPG / NTU / H36M / AMASS / 3DPW 均为非商用;GaitRec / AddBiomechanics / Daphnet / PhysioNet / CMU MoCap / AIST++ / UI-PRMD 可商用。

## 第四部分:对项目预研的五条启示

1. **产品形态已被验证,闭环尚未有人做**:LINDERA(德国)、LocoStep(日本)验证了"手机视频→步态/跌倒风险",日本厚労省课题验证了"视频→功能分级";但"分型+肌力+处方"全闭环全球空白——机会真实存在。
2. **MVP 应做参数层+分型,肌力走间接推断**:单目测时空参数已被临床验证;单目→3D→动力学仍在科研前沿(OpenCap Monocular 仅 2026 年刚出)。建议肌力分级用功能动作(坐站、单腿站)间接推断,而非直接动力学反演。
3. **监管分档可选**:美国 FDA-listed(OneStep 式,门槛低)/ Class II;德国 DiGA/DiPA;中国 NMPA 已有"步态评估与训练系统"二类证先例。先定位"健康管理/运动指导"可显著降低门槛——竞品几乎都这样起步。
4. **数据与循证是最大长期壁垒**:FARSEEING、世界跌倒预防指南、Otago 训练体系可低成本引入;若能积累"中国社区老年人视频步态+结局"数据集,将是国际竞品不具备的资产——预研阶段就按可发表、可注册标准设计采集。
5. **商业模式要与技术同等优先验证**:老年 C 端家庭付费全球无成功先例,优先考虑子女付费、社区/长护险合作、或 LINDERA 式 B2B2C。
