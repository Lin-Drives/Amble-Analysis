# 公开步态数据集调研报告(截至 2026 年初核实)

> 调研目的:为「单目手机视频 → 姿态估计 → 步态时空参数/关节角度 → 肌力与关节问题推断 → 康复建议」老年康复 App 预研可用的公开视频/骨骼步态数据集。
> 所有"获取方式/许可/规模"均来自 2026 年 2 月前后实际检索与官网页面核实;无法核实的条目已明确标注。

## 五、重点问题的核实结论

1. **OU-ISIR 是否有年龄标签?** ✅ 有。OU-MVLP 的 subject list 附带**年龄(2–87 岁)与性别**;OULP-Age(63,846 人,2–90 岁)专为年龄估计设计,附年龄+性别。但注意**均不发布 RGB 视频**(隐私),发布的是轮廓/GEI/姿态序列。每个子库需**单独**签协议。
2. **GaitRec 申请流程?** ✅ 无需申请。2026-02 核实为 figshare 开放 collection(DOI: 10.6084/m9.figshare.c.4788012),CC BY 4.0 直接下载。⚠️ 但要纠正预期:公开版**只有 GRF/COP 时序 + 元数据**,没有 marker 动捕、没有视频。
3. **PhysioNet 哪些需要 credentialed access?** ✅ 本文涉及的步态库(gaitpdb、gaitdb、gaitndd)**全部是 Open Access,不需要 credentialed access**;PhysioNet 的 credentialed access 只针对 MIMIC 等临床病历类数据。Daphnet 不在 PhysioNet,在 UCI(CC BY 4.0)。
4. **CASIA 是否还能下载?** ✅ 能。官网 2026-02 在线:A/B/C 轮廓图**免申请直接下载**(16M/628M/66M);含 RGB 视频的完整库(约 10GB)仍需签 Release Agreement 发邮件(casia_gait@nlpr.ia.ac.cn)后 FTP 下载。CASIA-B*(重分割裁剪 RGB)走同一申请流程。
5. **TUM-GAID** ❌ 官方已停止发布,不要再用。**SOTON** ❌ 未找到有效下载渠道。**USF** ✅ 可获取但需机构法务签约+邮寄 1.5TB 硬盘+出口管制,周期约 3 个月。

## 六、按 Phase 0(概念验证)需求的数据集优先级建议

**Phase 0 目标拆解**:① 手机视频→姿态/骨架(已有成熟预训练模型,缺的是步态领域微调数据);② 骨架→步态时空参数/关节角(需要步态真值);③ 骨架→肌力/关节问题(需要**临床标签**与**动力学真值**);④ 目标人群是**老年人/患者**。

### 第一梯队(立即获取,直接对口)
1. **GAVD** — 唯一直接可下的「RGB 视频 + 临床异常标注」集合(1,874 段),先用来验证视频→异常步态分类可行性。注意链接清单形式,尽早缓存。
2. **CARE-PD** — 「视频→SMPL→临床严重度」完整范式 + 现成 benchmark;CC-BY-NC 对科研 POC 无妨碍(产品化前需另行评估)。
3. **OpenCap / OpenCap Monocular 数据与代码** — 用其管线先把「单目视频→关节角度→关节力矩/肌肉力」打通,这是 Phase 0 最快的工程路径;其验证数据可作为本方案的精度基准。

### 第二梯队(1–2 周内获取,提供监督真值)
4. **AddBiomechanics Dataset**(CC BY 4.0 直接下载)— 273 人物理一致性动力学真值,训练/蒸馏「运动学→关节力矩与肌力」模型的核心资源。
5. **MOBILISE-D TVS**(Zenodo 直接下载)— 老年人+PD/MS/髋部骨折等队列的步态参数金标准,用于验证从视频估计的时空参数是否达到临床可参考精度。
6. **GaitRec**(figshare 直接下载)— 最大的关节病变临床标签库(髋/膝/踝/跟骨),用于「步态模式→病变部位分类」任务定义与迁移学习。

### 第三梯队(申请制,用于规模化预训练)
7. **OU-MVLP + OUMVLP-Pose**(签协议)— 万人级带年龄标签,做骨架序列自监督预训练,覆盖 2–87 岁年龄分布。
8. **CASIA-B/B\***(签协议)— 少量 RGB 真值用于领域微调与评测对比。
9. **Gait3D**(签协议)— SMPL 真值,野外场景 3D 姿态预训练。

### 第四梯队(按需)
10. PhysioNet 三个小库(gaitpdb/gaitdb/gaitndd)— 病理步态时空参数分布先验,半天即可拿到。
11. Fukuchi/Lencioni/Gutenberg — 含老年人的健康步态动捕补充。
12. 跌倒数据集(UR Fall、Le2i、UP-Fall 等)— 仅当产品规划加入跌倒风险评估功能时再引入。

### Phase 0 关键缺口提示
- **「老年人 RGB 步行视频 + 肌力/关节临床标签」的公开数据集目前不存在**。CARE-PD(PD)与 GAVD(混合病理)是最接近的替代;更完整的标签需通过:① 与康复机构合作自采(参考 OpenCap 流程,10 分钟即可完成一例采集);② 用 OpenCap/OpenCap Monocular 对公开视频数据集做"伪标签"生成。
- 商用合规注意:CCPG、CARE-PD 为**非商用**;GaitRec、AddBiomechanics、Daphnet、PhysioNet 步态库为 CC BY 4.0/开放;MOBILISE-D 为 CC BY-NC-ND。Phase 0 科研验证均可使用,产品化阶段需逐项重新评估。
