# 安步 Amble · 步态分析 Demo (W1)

手机浏览器打开即用的步态分析第一版：正面拍摄走向镜头（约 5 米、≤20 秒），
MediaPipe PoseLandmarker 端侧实时骨架叠加，输出 4 项指标（步频/步速/对称性/躯干摇晃）的
红黄绿信号灯报告。视频仅在本机处理，无后端、无构建步骤。

## 文件

| 文件 | 说明 |
|---|---|
| `index.html` | 三个页面：引导 → 拍摄/上传 → 报告 |
| `app.js` | 模型加载、摄像头/文件两种输入、分析管线、指标计算、报告渲染 |
| `styles.css` | 移动端优先，暖色系（米白 → 青绿） |
| `models/pose_landmarker_lite.task` | MediaPipe 姿态模型（约 5.5 MB，本地优先加载，失败回退公网 URL） |

## 本地运行

```bash
cd <仓库根目录>
python3 -m http.server 7100
# 浏览器打开 http://localhost:7100/demo/
```

桌面端开发测试可直接用「上传本地视频」模式（建议 MP4/H.264）。

## 手机实测

getUserMedia 要求安全上下文（HTTPS 或 localhost），手机局域网访问 `http://<电脑IP>:7100/demo/`
会被浏览器拦截摄像头权限。可选方案：

- `ngrok http 7100` 或 `npx localtunnel --port 7100`，用生成的 HTTPS 地址访问
- 或部署到任意静态 HTTPS 托管（GitHub Pages / Vercel 等）

## 指标口径（demo 简化版，参考区间基于公开文献硬编码）

- 步频：左右踝横向间距序列的峰值计数 ÷ 时长（绿 90–115 步/分）
- 步速：用户输入行走距离 ÷ 分析时长（<1.0 红 / 1.0–1.2 黄 / >1.2 绿 m/s）
- 左右对称性：左右踝相对身体中线（双肩+双髋中点连线）摆动幅度之比（≥90% 绿 / 80–90% 黄）
- 躯干摇晃：双肩中点横向峰峰值 ÷ 平均肩宽（<0.15 绿 / 0.15–0.30 黄 / >0.30 红）
