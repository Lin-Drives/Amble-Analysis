# 安步 Amble

![安步 Amble](assets/amble-cover.png)

> 用手机拍一段走路视频,30 秒内给你一份看得懂的体态/步态报告。

## 这是什么

安步(Amble)是一个步态/体态分析应用的 demo 项目:用普通手机摄像头拍摄行走视频,通过端侧 AI 姿态估计,输出普通人能看懂的健康参考指标。

项目初衷:大量中老年人存在步态退化、跌倒风险升高的问题,年轻人的体态问题也日益普遍,而普通家庭不具备早期识别和介入的专业知识。安步想让步态评估像测体温一样简单。

**当前阶段:MVP demo 开发中。** 原则是能跑起来、能给真人用、能收到反馈。
